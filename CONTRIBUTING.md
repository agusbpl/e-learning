# Contribuir a Glosa

Para cambios amplios, abrí primero un issue. En un pull request explicá el motivo, el comportamiento esperado y cómo lo verificaste. Usá datos temporales y ejemplos autorizados. No incluyas bases personales, PDFs restringidos, respaldos, claves ni respuestas reales de estudiantes.

Ejecutá las pruebas pertinentes de [desarrollo](docs/desarrollo.md). Para cursos, actividades, rúbricas, feedback o continuaciones, seguí [evaluación rigurosa](docs/evaluacion-rigurosa.md), conservá IDs y trazabilidad, y separá validación mecánica de revisión semántica.

Las contribuciones aceptadas se distribuyen bajo [Apache License 2.0](LICENSE), conforme a su sección 5. Se pide un `Signed-off-by` en cada commit conforme al [Developer Certificate of Origin 1.1](https://developercertificate.org/), para declarar que podés aportar el trabajo bajo esa licencia. Agregalo con `git commit -s`: `Signed-off-by: Tu Nombre <tu-email>`. Tu firma y los metadatos del commit serán públicos: elegí una identidad y un correo públicos, por ejemplo el correo noreply de GitHub, antes de aportar. El DCO no es una cesión ni una CLA. Conservás tus derechos sobre la contribución; no se promete exclusividad comercial futura y la licencia permite usos comerciales.

Para vulnerabilidades, seguí [SECURITY.md](SECURITY.md) antes de abrir un issue público. El [código de conducta](CODE_OF_CONDUCT.md) rige la interacción del proyecto.
