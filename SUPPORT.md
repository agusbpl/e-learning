# Ayuda

Para dudas de uso o instalación, consultá [README.md](README.md), [desarrollo](docs/desarrollo.md) y [privacidad](docs/privacidad.md). Si seguís bloqueado, abrí un issue con pasos para reproducir, sistema, versión o commit y mensaje de error depurado. No adjuntes secretos, PDFs privados, historial ni respaldos. No hay plazo de soporte garantizado.

Para vulnerabilidades, usá [SECURITY.md](SECURITY.md). Para propuestas y parches, seguí [CONTRIBUTING.md](CONTRIBUTING.md).
