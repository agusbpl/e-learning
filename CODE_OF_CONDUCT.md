# Código de conducta

Participá con respeto, criticá ideas con argumentos, respetá identidades y límites personales, y evitá acoso, insultos, intimidación, discriminación y publicación de información privada sin consentimiento.

Este código se aplica a issues, pull requests y otros espacios del proyecto. La persona mantenedora puede editar, ocultar o cerrar contenido que lo infrinja y limitar la participación ante conductas graves o reiteradas. Para denunciar una conducta, podés abrir un issue breve solicitando contacto privado, sin nombres, detalles sensibles ni evidencias personales. Acordá el canal con la persona mantenedora antes de enviar esos detalles. Las vulnerabilidades siguen [SECURITY.md](SECURITY.md).
